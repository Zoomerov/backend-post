Hedgedcurl

MAIN PARAM:

-t or --time -> is a parameter of time for "timeout" when we try request server by http protocol
-h or --help -> is a command to call Help Hedgedcurl file (this file)

examples of using hedgedcurl:

# async call for some servers. will return first answer without network error or timeout limit.
./hedgedcurl https://www.gosuslugi.ru https://www.prnhub.com https://memepedia.ru https://www.dota2.com

# 5 seconds timeout
./hedgedcurl -t 5 https://httpbin.org/delay/1 https://httpbin.org/delay/10

# call help file
./hedgedcurl --help
